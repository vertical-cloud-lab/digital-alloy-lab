## Start here

If you read nothing else in this folder, read these three files in order:

1. **`FAQ.md`** — plain-English answers to the questions that usually
   come up first ("what is a subaward vs. a vendor PO", "do we have to use our NICRA or can
   we use the 15% de minimis", "what reports do we owe DOE", "who owns
   the IP"). 12–15 Q&A.
2. **`WALKTHROUGH.md`** — 7-day step-by-step with checkboxes. Each step
   names the right person at Valimet (signatory vs. contracts vs.
   technical), points at the right file in this folder, and lists the
   expected output.
3. **`01-valimet-loc-prefilled.md`** — the Letter of Commitment text,
   pre-filled. Six bracketed fields. Drop on Valimet letterhead, sign,
   PDF.

> **FAQ.md and WALKTHROUGH.md are produced under Bundle 2 of this
> outreach effort and live in this same `letters/` directory.** If you
> received this packet and either file is missing, request it from
> Sterling Baird before starting.

## (i) What to sign

**One document on Valimet letterhead:** the Letter of Commitment
(`01-valimet-loc-prefilled.md`), printed on letterhead, signed by an
officer authorized to bind Valimet, Inc. to a legally binding
agreement, and returned as a PDF.

That's the only signature that flows into the DOE submission package.
Everything else in this folder is supporting documentation that flows
into the BYU subaward agreement (executed *after* DOE award) and/or
into the BYU Office of Sponsored Programs' subrecipient risk
assessment file.
