## Portal rules (per symposium organizers)

- **150 word maximum** for the abstract body.
- **Initial capitalization only for the title** (sentence case — not Title Case).
- **No hard returns**; let lines wrap naturally when pasted into the portal.
- Special characters and formatting use embedded codes (e.g. `\8776;` for ≈,
  `\8805;` for ≥, `\215;` for ×, `<i>...</i>` for italics, `<sub>`/`<sup>`
  for sub-/superscripts). See `submission.txt` for the substitutions used.
- "Preview My Abstract" must be clicked in the portal before final submission
  to verify rendering.
