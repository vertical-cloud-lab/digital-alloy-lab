# NSF grant requirements, guidelines, and best practices — sources

Resources collected to support proposal preparation for NSF mechanisms (PAPPG-governed
solicitations such as EAGER, CAREER, standard research grants, and the GENESIS Mission
program). Files in this directory are local copies of publicly distributed documents.
URLs and retrieval dates are recorded so the originals can be re-fetched if NSF updates
them.

> This is a private repository used like personal/lab cloud storage. Materials
> reproduced from third-party publishers (notably Grant Writers' Seminars &
> Workshops below) are included only for internal reference and must not be
> redistributed publicly.

All files retrieved 2026-05-06 unless otherwise noted.

## LLM-friendly text extractions

Plain-text (markdown) extractions of every PDF in this directory live in
`../nsf-resources-text/`, with the PAPPG split per-chapter so each file fits in
a typical LLM context window. See:

* [`../nsf-resources-text/INDEX.md`](../nsf-resources-text/INDEX.md) — token-budgeted index of all extractions.
* [`../nsf-resources-text/MOCK_REVIEWER_PLAYBOOK.md`](../nsf-resources-text/MOCK_REVIEWER_PLAYBOOK.md) — system-prompt + checklists that turn the corpus into an LLM-driven mock NSF reviewer.

## Grant Writers' Seminars & Workshops (GWSW) — `grant-writers-seminars-workshops/`

GWSW (Grant Central, https://www.grantcentral.com/) publishes the *Grant Application
Writer's Workbook* series by Stephen W. Russell and David C. Morrison, the most widely
recommended structured curriculum for federal grant writing. The PDFs below are sample
chapters / front-matter that GWSW themselves publish freely on grantcentral.com to
preview the workbooks.

**Copyright notice:** these files are © Grant Writers' Seminars & Workshops, LLC.
They are mirrored here only for internal reference within this private lab repository.
Do not redistribute. To purchase the full workbooks (≈$70 each), see
https://www.grantcentral.com/workbooks/ .
