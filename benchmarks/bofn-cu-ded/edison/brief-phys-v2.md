Follow-up review of a physics-based "truth" for a synthetic copper-alloy benchmark, after a refit. Central question: **does the evidence support a nickel floor (a minimum Ni content below which no alloy can pass 30-day seawater immersion "no worse than" a copper-nickel reference), and would it justify restricting the search space?**

Context. Alloys are Cu-Ni-Al-Fe-Mn (Ni 0-30, Al 0-9.5, Fe 0-4.5, Mn 0-4 wt%, Cu balance), deposited by blown-powder DED. An alloy counts only if it passes 30-day immersion no worse than dense 90-10 Cu-Ni (C70600) by default, or 70-30 Cu-Ni (C71500) as the stricter bar. The immersion node is a film corrosion model fitted only to same-test seawater data (ratios between alloys in the same study, with one intercept per study): ln rate = a_study + b_Ni (1 - exp(-Ni/5)) + b_Al Al + b_Al2 Al^2/10 + b_Fe min(Fe, 1.5), with b_Ni <= 0 and b_Fe <= 0 imposed (the film mechanism) and a weak ridge. The first fit (16 rates, 6 studies) had no copper or low-Ni data; an unconstrained linear version made Ni look harmful. This refit adds 14 rates from 5 studies found by a literature search (`copper-anchor.md`): Ravindran 1983 (copper 61 vs 22.5 um/y for 90-10 and 70-30, 120 d), Wheatfall 1967 via Gdowski 1991, Cohen and Whitted 1971 via Banning and Oden 1973 (hot brine, with two aluminum bronzes), Al-Fozan and Malik 2008. The CALPHAD node uses an 864-composition pycalphad grid (MatCalc mc_ni); the proposal's search-space limits are applied (liquidus <= 1,250 C, Cu >= 65 wt%, Ni >= Fe above 7 wt% Al, Fe <= 2.3 wt% below 1.5 wt% Al).
