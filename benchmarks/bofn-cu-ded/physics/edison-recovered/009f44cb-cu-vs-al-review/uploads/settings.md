# Settings of the uploaded runs

- Python 3.12.3, torch 2.14.1+cpu, botorch 0.18.1, gpytorch 1.15.2; CPU only, one thread per run.
- pKGFN Monte Carlo (results/, code version 2026-10-27): S_ACQ = 64 base samples, N_CAND = 16 candidates per stage, N_POOL = 512 Sobol designs per iteration, 32 + 16 anchors (top posterior mean, top EI) plus every deposited design in the inner-max set (deduplicated), 24 perturbations of each of the 8 best pool designs (the aluminum benchmark's production settings); 10 Gauss-Hermite nodes for one-output stages, a 2-point product rule (16 points) for the four CALPHAD outputs. The first copper sweep (quality/results-light/) ran S_ACQ = 32, N_CAND = 10, N_POOL = 256, 24 + 12 anchors, 16 perturbations, with the fallback's EI test including the 1e-9 tie-break. Every run stores its settings.
- Corrosion-aware tiered screening (tiered_ni): the shortlist keeps only compositions with Ni >= 10 wt% (scaled 0.333); the four strongest net of burden that pass the crack screen, filled when fewer than four pass with the eligible compositions of lowest solidification index f. Everything else as tiered.
- tiered_ni_ref: the same shortlist; a build goes to immersion if its one-hour screen is at least that of a dense C70600 (90-10 Cu-Ni) reference coupon (w_ref, stored in each run; 0.707 at eta = 1) instead of the spec's top-quartile gate.
- No-gate ablation (compare/results-nogate/, BOFN_NOGATE=1): J = U - 0.3 B on the same network, stages, costs and seeds; its optimum is in compare/landscape.json.
- Seed data per seed: CALPHAD on 32 Sobol compositions plus 5 random designs through every stage; spend counted from zero afterwards. Budget $100,000 of new spend.
- Costs (USD): {"C": 10.0, "A": 400.0, "U": 500.0, "M": 1500.0, "S": 100.0, "T": 200.0, "K": 50.0, "I": 400.0}; the first Mines session on a lot adds the $1,600 2 kg scale-up ($3,100 in all); a scaled-up lot supports 4 sessions; a full chain on a new composition is $4,760.
- Truth constants: crack onset F_CRACK = 0.56, CALPHAD screen F_SAFE = 0.34, Utah power cap 0.5, immersion gate scale 0.05, lambda = 0.3, m_ref = 0.849135.
- Screening policies: Utah density gate rho_u >= 0.5; one-hour screen gate = the 75% quantile of every w observed so far; tiered shortlist: top 4 of 256 compositions; funnel k = (12, 6, 3, 3); audit near-cutoff margins {'A': 0.03, 'M': 0.05, 'I': 0.03}.
- Required properties of the truth (from the specification; checked by check_truth.py, results in truth_tables.md): (1) at (kappa, eta) = (1, 1) the optimum fails the CALPHAD crack screen or ranks below the top quartile of dense candidates on the one-hour screen, so tiered screening cannot reach it; at (0, 0) the screens keep at least 85% of the optimum; (2) C71500 passes immersion by definition (m_ref), C95800 (NAB) is stronger and, deposited fast and cool, carries beta-prime and fails immersion, C70600 is weaker, uses less nickel and passes; (3) the optimum is a ridge in (P, v), not a point; (4) copper-rich compositions (low Ni and Al) cannot fuse at Utah's power cap but can at Mines.
- True optima per (kappa, eta) cell, by multi-start local search from the best of 400,000 random designs (truth_tables.json): (1, 1): J* = 0.492187 at x = [0.434, 0.585, 0.5, 0.0, 0.643, 0.582, 0.343]; (0, 0): J* = 0.381562 at x = [0.319, 0.375, 0.401, 0.0, 0.504, 0.627, 0.476]; (1, 0): J* = 0.492187 at x = [0.434, 0.585, 0.5, 0.0, 0.643, 0.582, 0.343]; (0, 1): J* = 0.381562 at x = [0.319, 0.375, 0.401, 0.0, 0.504, 0.627, 0.476].
- Runs in results/: 142 JSON files, as results/k<kappa>e<eta>/<policy>_s<seed>.json.
