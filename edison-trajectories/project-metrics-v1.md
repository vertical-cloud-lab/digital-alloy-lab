# FLAIME Phase I — Project Metrics (Draft v1)

*Initial metrics for the FLAIME Genesis Mission Phase I proposal. To be refined via Edison Scientific feedback.*

## Proposed Metrics — v1 (Pre-Edison)

### Category 1: Throughput & Efficiency

| Metric | Target (9 months) | Measurement Method |
|---|---|---|
| Unique compositions synthesized | ≥400 | Lab inventory count |
| Compositions per week (steady state) | ≥15 | Weekly throughput log |
| Full pipeline cycle time (1 composition) | ≤3 days | Timestamped workflow tracker |
| CALPHAD compositions screened | ≥2,000 | Thermo-Calc batch log |
| CALPHAD-to-experiment funnel ratio | ≥5:1 | Screened / synthesized |
| Powder batches atomized | ≥400 | Atomization run log |
| LPBF builds completed | ≥400 | Build log at U of U |
| Tensile specimens tested (ASTM E8/E8M) | ≥800 | Testing log (≥2 per composition) |

### Category 2: Material Performance

| Metric | Target | Measurement Method |
|---|---|---|
| Best Al-Ce-X YS discovered | ≥350 MPa | ASTM E8/E8M tensile |
| Best Al-Ce-X UTS discovered | ≥450 MPa | ASTM E8/E8M tensile |
| Best Al-Ce-X elongation discovered | ≥8% | ASTM E8/E8M tensile |
| Compositions exceeding AlSi10Mg baseline | ≥30 | Comparison to published AlSi10Mg |
| Alloy systems explored | ≥3 families | Al-Ce-X, Al-Cu-X, Al-Si variants |
| Pareto-optimal compositions (YS vs EL) | ≥10 | Pareto front analysis |

### Category 3: AI/Autonomy Performance

| Metric | Target | Measurement Method |
|---|---|---|
| BOFN sample efficiency vs random | ≥2× | Retrospective comparison |
| BOFN cumulative regret improvement | ≥30% reduction vs standard BO | Benchmark comparison |
| Cost-aware node routing savings | ≥20% experimental $ saved | Budget tracking per composition |
| Model prediction accuracy (R² for YS) | ≥0.7 | Leave-one-out cross-validation |
| Autonomous decision cycles completed | ≥100 | BOFN iteration log |
| Human intervention rate | ≤10% of decisions | Override tracking |

### Category 4: Sustainability & Cost Awareness

| Metric | Target | Measurement Method |
|---|---|---|
| Alloy raw material cost ($/kg) | Track for all compositions | Elemental cost calculation |
| Supply risk score per composition | Track for all compositions | DOE/USGS criticality index |
| Compositions on Pareto front (performance vs cost) | ≥5 | Multi-objective analysis |
| Ce fraction utilization (earth-abundant RE use) | Document Ce sourcing narrative | Literature/vendor data |
| Recyclability compatibility (Al scrap stream) | Assess for top 10 alloys | Expert assessment + literature |
| Embodied energy per composition (est.) | Track trend | Process energy monitoring |

### Category 5: Data & Dissemination

| Metric | Target | Measurement Method |
|---|---|---|
| FAIR datasets published | ≥1 major dataset | Zenodo/Materials Commons DOI |
| Journal publications submitted | ≥1 | Submission record |
| Conference presentations | ≥1 | TMS/MS&T abstract |
| Open-source code releases | ≥1 (BOFN pipeline) | GitHub release |
| Student training completions | 12 (all team members) | Training log |

### Category 6: Process Quality

| Metric | Target | Measurement Method |
|---|---|---|
| Powder yield in AM-suitable range (15–63 μm) | ≥40% | PSD analysis per batch |
| Powder sphericity | ≥0.85 | Image analysis |
| LPBF relative density | ≥99% | Archimedes method |
| Tensile test replicate variability (CoV for YS) | ≤10% | Statistical analysis |
| Build success rate | ≥90% | Build log |
| Atomization success rate | ≥95% | Run log |
