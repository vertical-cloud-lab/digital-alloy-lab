# Open-Source Simulation Tools and Methods for Alloy Design and Additive Manufacturing Modeling

This review surveys the landscape of open-source computational tools spanning thermodynamic modeling, atomistic simulation, mesoscale microstructure evolution, continuum-scale process modeling, machine learning, databases, and workflow automation relevant to alloy development for laser powder bed fusion (LPBF) additive manufacturing.

## 1. CALPHAD Tools

### pycalphad
pycalphad is an open-source Python library (MIT license) for CALPHAD-based computational thermodynamics. It uses symbolic representations of Gibbs energy models, enabling run-time manipulation of phase models and database entries—a capability that distinguishes it from other CALPHAD implementations (otis2024pycalphadcalphadbasedcomputational pages 1-3). The code supports multi-component, multi-phase equilibrium calculations via Gibbs energy minimization with full support for the compound energy formalism (CEF) and reads/writes standard TDB-format databases (otis2024pycalphadcalphadbasedcomputational pages 1-3). Its programmatic Python interface makes it well suited for high-throughput screening of alloy compositions and integration into automated workflows. A key limitation is that it can be slower than commercial solvers for very large multicomponent systems.

### OpenCalphad
OpenCalphad (OC) is distributed under the GNU GPL license and is written in Fortran/C (sundman2015opencalphada pages 1-3). It implements the standard multicomponent CEF model with support for multiple sublattices, magnetism, composition-dependent parameters, and properties such as molar volume and thermal expansion (sundman2015opencalphada pages 12-13). OC features a simple programming interface specifically designed to facilitate integration into external simulation codes (e.g., phase-field, diffusion) for ICME-type applications (sundman2015opencalphada pages 1-3). Limitations include the absence of built-in uncertainty quantification for CALPHAD results, and finding the true global equilibrium is not always guaranteed (sundman2015opencalphada pages 13-14, sundman2015opencalphada pages 10-12). OC is actively maintained and encourages community contributions.

### Scheil Solidification Module
The open-source `scheil` Python package implements Scheil-Gulliver solidification simulations on top of pycalphad (bocklund2020scheilgulliversimulationsfor pages 6-10, bocklund2020scheilgulliversimulationsfor pages 1-6). The Scheil-Gulliver model—assuming a well-mixed liquid and negligible back-diffusion in the solid—is particularly appropriate for additive manufacturing due to the rapid solidification conditions prevalent in LPBF (bocklund2020scheilgulliversimulationsfor pages 1-6). The package supports high-throughput screening of composition gradients, transparent handling of order-disorder models, and uses any Gibbs energy model available in pycalphad (bocklund2020scheilgulliversimulationsfor pages 6-10). It has been validated for designing functionally graded materials, where Scheil predictions better matched experimentally observed non-equilibrium phases than equilibrium calculations (bocklund2020scheilgulliversimulationsfor pages 18-22). It can also be used to evaluate solidification cracking susceptibility indices for alloy screening (michael2023numericalstudyof pages 16-20).

## 2. Density Functional Theory Codes

### Quantum ESPRESSO
Quantum ESPRESSO (QE) is an integrated, modular suite for DFT calculations distributed under the GNU General Public License (giannozzi2009quantumespressoa pages 3-5, giannozzi2009quantumespressoa pages 1-3). It uses plane-wave basis sets with norm-conserving, ultrasoft, and projector-augmented wave (PAW) pseudopotentials. Key capabilities include ground-state calculations, structural optimization, density functional perturbation theory (DFPT) for phonons and electron-phonon coupling, ab initio molecular dynamics, spin-orbit coupling, and support for Hubbard U corrections (giannozzi2009quantumespressoa pages 6-7, giannozzi2009quantumespressoa pages 9-10). QE is designed for massively parallel architectures and scales to thousands of processors, with a GPU branch providing up to 14× speedups (sarker2025evaluationofcomputational pages 29-31). For alloy design, QE can compute formation energies, elastic constants, phonon spectra, and thermodynamic properties that feed into CALPHAD database assessments.

### GPAW
GPAW is a Python-based DFT code that uniquely supports three basis-set modes: real-space grids, plane waves, and localized atomic orbitals (LCAO) (sarker2025evaluationofcomputational pages 29-31, sarker2025evaluationofcomputational pages 23-26). It is tightly integrated with the Atomistic Simulation Environment (ASE), serving as ASE's default first-principles calculator (lin2015materialsdatabasesinfrastructure pages 6-8). GPAW's flexibility in switching between real-space and plane-wave modes makes it well suited for disordered or inhomogeneous alloy systems (sarker2025evaluationofcomputational pages 23-26). GPU acceleration via CuPy provides approximately 8× speedup, and integration with ML tools (Amp, SchNetPack) enables accelerated workflows (sarker2025evaluationofcomputational pages 29-31). The code is distributed under GPL-compatible licenses. A precision benchmark across many DFT codes confirmed that both QE and GPAW yield reproducible equations of state for elemental crystals (bosoni2024howtoverify pages 16-18).

## 3. Molecular Dynamics

### LAMMPS
LAMMPS (Large-scale Atomic/Molecular Massively Parallel Simulator) is distributed under the GNU GPL and is the dominant open-source MD code for metallic alloy simulations. It implements fast parallel algorithms for short-range molecular dynamics and supports a wide variety of interatomic potentials relevant to metals, including EAM, MEAM, and Tersoff potentials (mahata2019effectsofsolidification pages 9-10). LAMMPS has been extensively used for simulating rapid directional solidification of alloys such as Al-Cu, investigating dendritic microstructure formation, solidification defects, and nanoscale mechanical properties under AM-relevant cooling conditions (mahata2019effectsofsolidification pages 9-10). It has also been employed for studying melt pool solidification epitaxial growth and bimetallic nanoparticle behavior during AM. The primary limitation is the requirement for validated interatomic potentials for the specific alloy system of interest; development of such potentials, including through machine-learned interatomic potentials, is an active research area.

### OpenMM
OpenMM (MIT license) is a highly optimized molecular dynamics toolkit primarily designed for biomolecular simulations. While it excels in GPU-accelerated soft-matter and protein simulations, its force-field ecosystem is not oriented toward metallic alloy simulations. It lacks native support for metallic bonding potentials (EAM, MEAM) that are essential for alloy property calculations, making it of limited direct relevance to LPBF alloy development.

## 4. Phase-Field Modeling

### MOOSE / MARMOT / MALAMUTE
MOOSE (Multiphysics Object-Oriented Simulation Environment) is an open-source (LGPL) C++ finite element framework developed at Idaho National Laboratory. Its Phase Field module enables coupling phase-field PDEs with mechanics and heat conduction via modular "kernels" and automatic differentiation for exact Jacobian computation (darabi2023multiscalemultiphysicsfembased pages 96-99). MARMOT, built on MOOSE, provides phase-field models for microstructure evolution including solidification, precipitation, and grain growth. MALAMUTE extends MOOSE specifically for additive manufacturing, implementing laser melt-pool modeling via Navier-Stokes with ALE mesh motion, level-set interface tracking, element activation for material deposition, and multi-scale coupling between process-scale thermal models and grain-growth phase-field simulations (biswas2024multiscaleandmachine pages 12-19, pitts2024modelingandsimulation pages 16-20, pitts2024modelingandsimulation pages 10-13, pitts2024modelingandsimulation pages 13-16). MALAMUTE also integrates machine-learning surrogate models (multi-output Gaussian processes) for accelerated thermal field prediction (biswas2024multiscaleandmachine pages 19-21). The primary limitation is the high computational cost of fully coupled 3D melt-pool and microstructure simulations.

### PRISMS-PF
PRISMS-PF is an open-source (LGPL) phase-field framework that employs a matrix-free finite element method combined with adaptive mesh refinement and explicit time integration (dewitt2020prismspfageneral pages 1-2). Benchmark testing demonstrated up to 12× speedups over representative finite-difference codes for particle growth problems, and comparable or better performance than implicit/semi-implicit frameworks for solidification benchmarks (dewitt2020prismspfageneral pages 1-2). PRISMS-PF supports arbitrary numbers of coupled governing equations and provides built-in functionality for nucleation and polycrystalline systems, making it suitable for dendritic solidification and precipitation studies relevant to AM alloys.

### OpenPhase
OpenPhase is an open-source (GPLv3) C++ phase-field library initiated in 2008, based on the multi-phase-field model (steinbach2023tutorial1openphase pages 1-6). It supports 1D/2D/3D simulations with multiple chemical components, phases, and grains, and provides OpenMP and MPI parallelization (steinbach2023tutorial1openphase pages 1-6). Demonstrated capabilities include equiaxed dendritic solidification, grain growth, and temperature/cooling protocol control with VTK output for visualization (steinbach2023tutorial2openphase pages 8-11). A commercial variant (OP Studio) adds GUI access and coupling to thermodynamic databases for multi-component diffusion. OpenPhase is command-line driven and requires C++ expertise for custom model extensions.

### FEniCS-based Phase-Field (PhaseFieldX)
PhaseFieldX is an open-source package built on FEniCSx for phase-field simulations including solidification and fracture. FEniCS provides automated FEM PDE solving with a high-level Python interface, making it accessible for researchers to implement custom phase-field formulations for AM microstructure modeling.

## 5. Finite Element and CFD Analysis for AM Process Simulation

### OpenFOAM
OpenFOAM is a C++ finite volume method (FVM) toolbox distributed under the GNU GPL (murer2021computationalfluiddynamics pages 56-59, kodman2024acomprehensivesurvey pages 9-11). It provides extensive CFD capabilities including incompressible/compressible flow, heat transfer, multiphase flow, and turbulence modeling on 3D unstructured polyhedral meshes. For AM applications, OpenFOAM has been used for melt pool hydrodynamics with thermal-capillary (Marangoni) convection, solidification modeling, and laser energy deposition simulations (murer2021computationalfluiddynamics pages 56-59). Limitations include a steep learning curve, limited built-in GUI, and the need for custom solver development for some AM-specific physics.

### FEniCS
FEniCS (LGPL license) is an automated finite element framework in Python/C++ for solving partial differential equations (kodman2024acomprehensivesurvey pages 9-11). Its strength lies in the high-level specification of variational formulations, enabling rapid prototyping of custom thermal-mechanical solvers for AM. FEniCS has been used for solidification front optimization and coupled thermo-mechanical problems. It is not a "black-box" solver—users must formulate weak forms of governing equations—but this flexibility enables implementation of novel physics relevant to LPBF.

### CalculiX
CalculiX is a GPL-licensed structural FEA code with an Abaqus-compatible input format (kodman2024acomprehensivesurvey pages 9-11). It supports linear and nonlinear static/dynamic analysis, heat transfer, and thermo-mechanical coupling. For AM applications, CalculiX can perform part-scale residual stress and distortion analysis. It has been coupled with OpenFOAM via preCICE for fluid-structure interaction simulations. Performance benchmarks show it runs approximately 1.4–1.6× slower than optimized compiled commercial solvers, a reasonable trade-off for its open-source accessibility.

## 6. Machine Learning Frameworks for Materials

### CGCNN (Crystal Graph Convolutional Neural Network)
CGCNN (MIT license) converts crystal structures into graph representations where nodes represent atoms and edges represent bonds, then applies graph convolutional layers for property prediction (omee2024structurebasedoutofdistribution(ood) pages 14-16). It was among the first GNN architectures for crystalline materials and demonstrates robust out-of-distribution performance relative to newer, more complex architectures (omee2024structurebasedoutofdistribution(ood) pages 14-16). For alloy design, CGCNN can predict formation energies, band gaps, and elastic moduli from crystal structures.

### MEGNet (MatErials Graph Network)
MEGNet (BSD license) extends graph neural networks with distinct node, edge, and global state attributes, enabling capture of both local bonding and global material characteristics (omee2024structurebasedoutofdistribution(ood) pages 14-16, van2506asurveyof pages 8-9). Trained on Materials Project data, MEGNet predicts formation energies and various properties for crystals and molecules. It has been integrated into broader atomistic modeling pipelines (van2506asurveyof pages 8-9).

### ALIGNN (Atomistic Line Graph Neural Network)
ALIGNN, developed at NIST, incorporates bond-angle information through a line graph representation, achieving state-of-the-art accuracy on multiple property prediction benchmarks (omee2024structurebasedoutofdistribution(ood) pages 14-16). It demonstrates comparatively robust performance on out-of-distribution materials prediction tasks, making it particularly relevant for screening novel alloy compositions beyond training data distributions.

### matminer and automatminer
matminer (BSD 3-Clause license) is a data mining and feature engineering library that generates descriptors (e.g., composition-based, structural, electronic) for materials from databases such as the Materials Project (omee2024structurebasedoutofdistribution(ood) pages 14-16). automatminer extends matminer with automated machine learning (AutoML) pipelines. These tools are valuable for building predictive models for alloy properties such as hardness, thermal conductivity, and printability metrics without requiring deep GNN expertise.

## 7. Thermodynamic Databases

### SGTE
The Scientific Group Thermodata Europe (SGTE) maintains comprehensive assessed thermodynamic databases covering many alloy systems. SGTE data underpin most commercial CALPHAD software (Thermo-Calc, FactSage) and serve as the industry reference standard (kattner2016thecalphadmethod pages 13-14). However, SGTE databases are proprietary and require consortium membership or commercial licenses for access.

### Cost-Free Alternatives
Several openly available databases in TDB format provide viable alternatives for academic and research use (kattner2016thecalphadmethod pages 13-14, kattner2016thecalphadmethod pages 17-19):
- **COST507**: A freely available thermochemical database for light metal alloys (Al, Mg, Ti systems), widely used with pycalphad for AM alloy screening (michael2023numericalstudyof pages 16-20, kattner2016thecalphadmethod pages 17-19).
- **NIST databases**: System-specific assessed databases including NIST-Ni (γ/γ′ equilibria in Ni-base superalloys), NIST-Sn (solder alloys), and NIST-Ni-mob (diffusion data) (kattner2016thecalphadmethod pages 13-14).
- **NIMS/MatNavi**: The National Institute for Materials Science provides publicly accessible thermodynamic data and phase diagram information.
- The TDB format, originally developed for Thermo-Calc, has become the de facto standard and is readable by pycalphad, OpenCalphad, and other open-source tools (kattner2016thecalphadmethod pages 13-14).

## 8. Workflow Managers for High-Throughput Computation

### AiiDA
AiiDA (MIT license) is a database-backed, Python-based workflow management system designed for high-throughput computational science with emphasis on data provenance and reproducibility (uhrin2021workflowsinaiida pages 1-2, p.2021commonworkflowsfor pages 11-12). It features an event-driven engine that scales from laptops to HPC systems, supports common schedulers (SLURM, PBS, SGE), and can manage thousands of concurrent jobs (uhrin2021workflowsinaiida pages 1-2, uhrin2021workflowsinaiida pages 10-11). AiiDA's plugin system enables integration with diverse simulation codes, and it has been deployed for code-agnostic workflows across eleven quantum engines (p.2021commonworkflowsfor pages 11-12). AiiDAlab provides a Jupyter-based graphical interface for non-specialists (wang2026makingatomisticmaterials pages 2-4, wang2026makingatomisticmaterials pages 8-10).

### FireWorks
FireWorks (modified BSD license) is a workflow execution framework capable of orchestrating thousands of parallel calculations with comprehensive job tracking, queue system integration (PBS, SLURM, SGE), and MongoDB-based data storage (mathew2017atomateahighlevel pages 2-3). It has been the primary execution engine for the Materials Project infrastructure and for atomate/atomate2 workflows (ganose2025atomate2modularworkflows pages 23-24, mathew2017atomateahighlevel pages 2-3).

### atomate2 and jobflow
atomate2 (modified BSD license) is a modular workflow framework built on the jobflow library that provides composable, code-agnostic workflows for high-throughput materials calculations (ganose2025atomate2modularworkflows pages 3-4, ganose2025atomate2modularworkflows pages 2-3). It supports multiple electronic structure codes (VASP, ABINIT, FHI-aims, CP2K) and machine-learned interatomic potentials, enabling heterogeneous workflows that chain different calculators (ganose2025atomate2modularworkflows pages 6-6). atomate2 retains full input/output provenance, offers automatic error handling and duplicate detection, and can execute via FireWorks or jobflow-remote (ganose2025atomate2modularworkflows pages 23-24). jobflow (MIT license) provides lightweight directed acyclic graph (DAG) workflow definitions in Python, and a recent Python Workflow Definition standard enables interoperability between AiiDA, jobflow, and pyiron ecosystems.

## Summary and Outlook

The open-source ecosystem for alloy design and LPBF additive manufacturing modeling has matured substantially, spanning all length scales from electronic structure (QE, GPAW) through atomistic dynamics (LAMMPS), mesoscale microstructure evolution (MOOSE/MALAMUTE, OpenPhase, PRISMS-PF), continuum process modeling (OpenFOAM, FEniCS, CalculiX), thermodynamic equilibrium and solidification (pycalphad, OpenCalphad, scheil), machine learning property prediction (CGCNN, MEGNet, ALIGNN, matminer), and high-throughput workflow orchestration (AiiDA, atomate2, FireWorks, jobflow). Key remaining challenges include the availability of validated thermodynamic databases for novel alloy systems (particularly high-entropy alloys), interatomic potentials for complex multicomponent alloys, uncertainty quantification across all modeling scales (sundman2015opencalphada pages 13-14), and the computational cost of fully coupled multiscale simulations linking process parameters to microstructure and properties.
