## Skill Definitions

| Skill | Description | Training Needed (if ○) |
|---|---|---|
| **Atomization** | Operating AMAZEMET rePOWDER induction module: feedstock loading, parameter setting, powder collection, sieving, QC | ~2 weeks hands-on training + SOP |
| **LPBF Operation** | Build plate prep, powder loading, parameter file management, build monitoring, post-processing (support removal, wire EDM) | ~1–2 weeks at U of U + machine certification |
| **Tensile Testing** | ASTM E8/E8M specimen prep, load frame operation, extensometer attachment, data acquisition, stress-strain analysis | ~1 week + equipment SOP |
| **Metallography & SEM** | Sample mounting/polishing, optical microscopy, SEM/EDS/EBSD operation, image analysis, density measurement | ~2–3 weeks + instrument access |
| **CALPHAD / Thermo-Calc** | Running batch Scheil calculations, interpreting phase diagrams, using TC-Python API, screening alloy compositions | ~2–4 weeks for computational users |
| **Python / Data** | Python scripting, data pipeline management, database operations, visualization (matplotlib, plotly), Jupyter | Varies; CS students may be ● already |
| **BO / ML** | Bayesian optimization concepts, BoTorch/BOFN, GP models, acquisition functions, multi-objective optimization | ~4 weeks guided learning; MS student core |
| **Safety Certified** | Lab safety (metal powders, inert gas, laser, chemical), PPE, hazmat handling, BYU EH&S requirements | ~1 week mandatory before lab access |

## Cross-Training Plan

All students receive baseline training in Months 1–2:

1. **Week 1:** Lab safety certification, PPE, powder handling SOPs
2. **Week 2:** Overview rotation through all 4 nodes (atomization → LPBF → tensile → SEM)
3. **Weeks 3–4:** Specialization training in primary role
4. **Weeks 5–8:** Supervised operation with increasing independence
5. **Ongoing:** Monthly cross-training sessions so ≥2 students can cover each critical role
