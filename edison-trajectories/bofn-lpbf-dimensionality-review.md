Question: We are developing a Bayesian Optimization over Function Networks (BOFN) framework
(Astudillo & Frazier 2021, NeurIPS) for autonomous alloy discovery, with the following
pipeline as a directed acyclic graph (DAG):

Node 0: CALPHAD screening (alloy composition → phase fractions, ~$1/eval)
Node 1: Ultrasonic atomization (phase fractions + atomization params → powder quality, ~$200/eval)
Node 2: LPBF printing (powder quality + LPBF process params → part density/quality, ~$500/eval)
Node 3: Mechanical characterization (part quality → yield strength, elongation, ~$300/eval)

Each node uses a Gaussian Process (GP) surrogate. The key challenge: LPBF (Node 2) involves
~36 processing parameters across 7 categories (beam/energy: 8, scan strategy: 8, layer/build: 4,
powder/feedstock: 6, atmosphere: 4, thermal: 3, machine-specific: 3), as documented by Oliveira
et al. 2020, Brika et al. 2020, and Adam Clare's community observation. Our current implementation
only models 2 LPBF parameters (laser power and scan speed), which is a gross oversimplification.

We propose the following approach to handle this high dimensionality within BOFN:

1. **Parameter tiering within Node 2**: Classify the 36 parameters into:
   - Tier A (actively optimized, ~6-8 params): power, speed, hatch spacing, layer thickness,
     scan pattern rotation, contour passes
   - Tier B (fixed per alloy family, ~8-10): gas type, recoater type, baseplate temp, spot size
   - Tier C (fixed per machine, ~15-18): wavelength, beam profile, chamber pressure, recoater speed

2. **Hierarchical sub-node decomposition**: Split Node 2 into sub-nodes within the DAG:
   - Node 2a: Energy delivery (power, speed, spot size → melt pool geometry)
   - Node 2b: Scan strategy (hatch, rotation, contour → layer quality)
   - Node 2c: Thermal management (preheat, dwell time → residual stress/distortion)
   - Node 2d: Integration (melt pool + layer quality + thermal → final part density)

3. **SAASBO sparsity priors**: Use SaasFullyBayesianSingleTaskGP with horseshoe priors at each
   sub-node to automatically identify which of the Tier A parameters matter most at each stage.

4. **Transfer learning across compositions**: LPBF parameters for similar alloy families
   (e.g., Al-Si-Mg variants) share similar optima. Use multi-task GPs or informative priors
   transferred from previously optimized compositions.

5. **Volumetric Energy Density (VED) as a learned composite feature**: While VED = P/(v*h*t)
   collapses 4 dimensions to 1 and is recognized as insufficient, it can serve as an informative
   feature alongside the raw parameters.

# Bayesian Optimization over Function Networks for Autonomous Alloy Discovery: A Comprehensive Technical Assessment

## (a) Hierarchical Sub-Node Decomposition within BOFN DAGs

The proposed hierarchical sub-node decomposition of Node 2 (LPBF printing) into sub-nodes 2a–2d is **theoretically sound** within the BOFN framework. Astudillo & Frazier (2021) formalize the objective as a directed acyclic function network of K node functions f₁,...,fₖ, where each node's output feeds its children, and each node function fₖ is modeled with an independent Gaussian process prior (astudillo2021bayesianoptimizationof pages 2-4, astudillo2021bayesianoptimizationof pages 1-2). The framework explicitly allows nodes to take arbitrary subsets of decision variables and parent outputs, so decomposing a single physical stage into multiple GP nodes fits naturally within the formal model (astudillo2021bayesianoptimizationof pages 2-4). The asymptotic consistency proof holds for arbitrary DAG topologies, and the method can exploit problem structure to leave regions unexplored rather than requiring dense sampling (astudillo2021bayesianoptimizationof pages 1-2).

Several extensions confirm this approach. Buathong & Frazier (2025) develop Fast p-KGFN for partial evaluations of function networks, where individual constituent nodes can be queried independently at different costs — directly analogous to your sub-node decomposition where, e.g., melt pool geometry (Node 2a) might be evaluable via simulation while final part density (Node 2d) requires a physical build (buathong2506fastbayesianoptimization pages 1-2, buathong2506fastbayesianoptimization pages 4-6). Kudva et al. (2025) introduce MOBONS for multi-objective BO over function networks, placing independent GP priors on each local network function and propagating uncertainty through the DAG via Thompson sampling (kudva2502multiobjectivebayesianoptimization pages 4-6, kudva2502multiobjectivebayesianoptimization pages 6-9). Kiroriwal et al. (2025) propose POGPN-JPSS, which frames multi-stage manufacturing as a causal DAG where nodes represent subprocesses with controllable inputs and parent outputs, and uses process expert knowledge to extract low-dimensional latent features from high-dimensional state data (kiroriwal2602jointparameterand pages 1-2).

A key practical benefit of sub-node decomposition is dimensionality reduction per node. Tooley (2021) demonstrates that decomposing a high-dimensional mapping into many low-dimensional sub-models (no sub-model having more than four inputs) serves as a structural prior that trades modeling bias for reduced per-node dimensionality and improved sample efficiency (tooley2021autotuningsparkwith pages 35-39). The DAG topology functions as a Bayesian prior whose influence diminishes with more data: missing arcs make the model treat effects as noise (slowing convergence), while surplus arcs enlarge the search space (tooley2021autotuningsparkwith pages 35-39). This is directly applicable to your proposed sub-node structure — if the decomposition into energy delivery, scan strategy, thermal management, and integration nodes reflects genuine physical causality, it will substantially improve GP modeling quality at each stage.

**Implementation recommendation:** The sub-node decomposition is well-justified. Each sub-node should have 2–4 input parameters, which is well within the regime where GPs excel. The intermediate outputs (melt pool geometry, layer quality, residual stress) serve as physically meaningful latent variables that reduce the effective dimensionality of the overall LPBF optimization.

**SAASBO** (Eriksson & Jankowiak, 2021, UAI) is the strongest candidate for your setting. The SAAS prior uses hierarchical horseshoe-style shrinkage on inverse squared lengthscales, forcing most ρᵢ toward zero while allowing a few to escape, producing a GP that automatically focuses on a small set of important inputs (eriksson2021highdimensionalbayesianoptimization pages 5-6). Critically, SAASBO can identify the relevant dimensions in approximately 20–30 evaluations (eriksson2021highdimensionalbayesianoptimization pages 5-6), which aligns well with typical LPBF campaign sizes. On rotated Hartmann functions with d=6 embedded in higher-dimensional spaces, SAASBO "outperforms the other methods and is able to quickly identify the most important parameters" (eriksson2021highdimensionalbayesianoptimization pages 16-17). The fully Bayesian treatment via NUTS provides robustness by averaging acquisition evaluations over GP hyperparameter samples (eriksson2021highdimensionalbayesianoptimization pages 5-6). SAASBO is natively available in BoTorch as `SaasFullyBayesianSingleTaskGP`.

**TuRBO** (Eriksson et al., 2019, NeurIPS) is an excellent practical alternative. It abandons a global surrogate in favor of multiple independent local GP models inside trust regions, with bandit-style allocation and Thompson sampling for batch selection (eriksson2019scalableglobaloptimization pages 1-2, eriksson2019scalableglobaloptimization pages 2-4). TuRBO's local modeling provides robustness to noise and avoids over-exploration of high-uncertainty regions, which is relevant for noisy LPBF experiments (eriksson2019scalableglobaloptimization pages 1-2). The comprehensive comparison by Santoni et al. (2024) on BBOB benchmarks confirms that trust-region approaches are "the most promising approach to improve BO" and that "SAASBO and TuRBO emerge as superior high-dimensional" methods (santoni2024comparisonofhighdimensional pages 5-7).

**REMBO** (Wang et al., 2016, JAIR) and **HeSBO** (Nayebi et al., 2019, ICML) are less suitable for your setting. Both require choosing an embedding dimension a priori, which is "not learned" and can lead to failure if chosen poorly (eriksson2021highdimensionalbayesianoptimization pages 7-9). REMBO "makes little progress after iteration 30" in some settings when the embedding is unlucky (eriksson2021highdimensionalbayesianoptimization pages 7-9). For 6–10 active parameters, the dimensionality is moderate enough that SAASBO or TuRBO can handle it directly without requiring random projections.

**MORBO** (Daulton et al., 2022, UAI) extends trust-region BO to multi-objective settings with coordinated trust regions that share observations and optimize hypervolume-based utilities (daulton2022multiobjectivebayesianoptimization pages 2-3, daulton2022multiobjectivebayesianoptimization pages 3-4). It is the first multi-objective BO method that scales to hundreds of parameters and thousands of evaluations (daulton2022multiobjectivebayesianoptimization pages 1-2). MORBO addresses TuRBO's limitation of independent trust regions by sharing observations and coordinating center selection for Pareto-front coverage (daulton2023bayesianoptimizationin pages 110-113, daulton2022multiobjectivebayesianoptimization pages 4-5). Use MORBO if Node 2 or the full pipeline requires simultaneous optimization of density, roughness, and strength.

**Recommended strategy for your BOFN sub-nodes:** Use SAASBO at each LPBF sub-node (2a–2d) with the Tier A parameters. The sparsity prior will automatically discover which of the 6–8 Tier A parameters matter most at each stage, which is exactly the behavior you want. For the integration sub-node (2d), if it involves multiple competing objectives, consider MORBO. Baird et al. (2022) demonstrated SAASBO successfully optimizing 23 hyperparameters over 100 iterations using Ax, confirming its practical viability for materials science applications.

**RGPE** (Feurer, Letham, Hutter & Bakshy, 2018) is the most practical choice for your application. RGPE constructs a weighted ensemble of base GP models (one per previously optimized alloy) plus the target GP, using ranking-loss-based weights estimated via bootstrap Monte Carlo (feurer2018practicaltransferlearning pages 6-8). The ranking loss counts misranked observation pairs, which directly targets the ordering needed for optimization rather than value-level accuracy (feurer2018practicaltransferlearning pages 6-8). The ensemble remains a Gaussian process, preserving standard BO machinery including closed-form EI, joint sampling, and parallelization (feurer2018practicaltransferlearning pages 8-11, feurer2018scalablemetalearningfor pages 1-3). Base models remain fixed and can be loaded from prior optimization campaigns, so the extra computational cost is only fitting the target GP and inferring ensemble weights (feurer2018practicaltransferlearning pages 8-11). RGPE empirically outperforms strong baselines including random search with 10× budget, and the TAF variant RGPE(TAF) is "frequently the best or statistically equivalent to the best across six benchmarks" (feurer2018practicaltransferlearning pages 18-20). RGPE is well-integrated into Ax warm-start workflows.

**TAF** (Wistuba, Schilling & Schmidt-Thieme, 2016/2018) transfers knowledge through the acquisition function rather than only the surrogate, combining target-task EI with source-task improvement terms (feurer2018practicaltransferlearning pages 3-6). However, TAF inherits the TST-R weighting scheme's sensitivity to a bandwidth hyperparameter ρ and can be skewed by correlated source tasks (feurer2018practicaltransferlearning pages 3-6). It lacks a standard BoTorch implementation.

**Multi-task GP** (Swersky, Snoek & Adams, 2013, NeurIPS) uses an intrinsic coregionalization kernel K_multi((x,t),(x',t')) = K_t(t,t') ⊗ K_x(x,x') to model correlations across tasks (alloy compositions) directly (swersky2013multitaskbayesianoptimization pages 1-3). This provides principled Bayesian transfer when alloy families are few and clearly related. However, complexity grows cubically with total observations across all tasks, making it less attractive when pooling many historical campaigns (swersky2013multitaskbayesianoptimization pages 1-3).

**Recommendation for your alloy discovery pipeline:** Start with RGPE as the default transfer mechanism. For each new alloy composition entering the LPBF optimization, instantiate base models from previously optimized compositions in the same family (e.g., Al-Si-Mg variants). The ranking-based weighting will automatically downweight dissimilar alloys. If you have only 2–3 closely related alloy families with moderate data, multi-task GP is a viable alternative that can model cross-task correlations more precisely. For integration into the BOFN framework, RGPE can be applied at each node independently — the Node 2 GP for a new alloy can use an RGPE ensemble built from Node 2 GPs of previously optimized alloys.

## (d) Multi-Dimensional Powder Feedstock Properties in the BOFN DAG

The BOFN framework naturally accommodates multi-dimensional intermediate outputs between nodes. While the original formulation by Astudillo & Frazier (2021) primarily presents scalar-valued node outputs for simplicity, the paper explicitly demonstrates nodes that output multi-dimensional vectors. For example, in the Fetch-and-Reach experiment, each node "produces as output the location of the arm" — a 3-dimensional vector — and the authors note this "can also be thought of as a function network with 9 single-output nodes" (astudillo2021bayesianoptimizationof pages 6-8). Similarly, the SIS epidemiological example uses two-dimensional state vectors propagated through the network (astudillo2021bayesianoptimizationof pages 8-9). Buathong & Frazier (2025) explicitly note that while they assume scalar outputs for simplicity, "the approach generalizes easily to vector (multi-dimensional) outputs" (buathong2506fastbayesianoptimization pages 1-2).

For your 6 powder feedstock properties (PSD parameters, morphology, flowability), there are two implementation strategies within BOFN:

**Strategy 1: Multiple scalar-output nodes.** Decompose Node 1 (ultrasonic atomization) into 6 parallel scalar-output nodes, each producing one powder property. These 6 outputs then serve as inputs to Node 2 sub-nodes alongside LPBF process parameters. The Fast p-KGFN algorithm explicitly handles this — it concatenates intermediate outputs from parent nodes with external inputs to form node-specific inputs, e.g., ẑ_{n,3} = (ŷ₁(x̂_n), ŷ₂(x̂_n), x̂_{n,3}) (buathong2506fastbayesianoptimization pages 4-6). This approach preserves scalar GP modeling at each node, which is computationally simpler and better-behaved.

**Strategy 2: Vector-valued intermediate outputs.** Model Node 1 as producing a 6-dimensional output vector using a multi-output GP (e.g., BoTorch's `MultiTaskGP` or `HigherOrderGP`), with Node 2 sub-nodes accepting this vector as part of their input. This is more compact but requires multi-output GP machinery.

**Recommended approach:** Use Strategy 1 (multiple scalar nodes) for its simplicity and GP modeling quality. However, apply dimensionality reduction to the 6 powder properties before feeding them into Node 2. Not all 6 powder parameters are equally informative for LPBF — PSD D50, flowability (Hausner ratio or Hall flow), and apparent density are typically the most predictive. A 2–3 dimensional summary (either via PCA on historical powder data or via physically motivated composites) fed into each LPBF sub-node keeps the per-node input dimensionality manageable. The BOFN framework's acquisition function will propagate uncertainty through these intermediate connections via sample average approximation (astudillo2021bayesianoptimizationof pages 2-4, astudillo2021bayesianoptimizationof pages 4-6).

Kiroriwal et al. (2025) provide direct precedent for this approach in manufacturing: their POGPN-JPSS framework uses expert knowledge to extract low-dimensional latent features h(v) from high-dimensional state data S(v) at each manufacturing subprocess node, and these features are then used in the GP network for improved BO (kiroriwal2602jointparameterand pages 1-2). This is precisely the strategy needed for compressing powder feedstock characterization into informative features for the LPBF node.

## (e) Published Work on Bayesian Optimization of LPBF Process Parameters

Several published works directly apply Bayesian optimization to LPBF/SLM process parameter optimization:

**Chepiga et al. (2023, Materials)** applied multi-objective Bayesian optimization (specifically DGEMO via the AutoOED platform) to optimize L-PBF process parameters for stainless steel 316L, targeting hardness and porosity simultaneously. Using a GP surrogate trained on 57 empirical data points, they obtained three Pareto-optimal solutions in just six iterations, achieving hardness of 224–235 HV and porosity of 0.2–0.37% (chepiga2023processparameterselection pages 9-10, chepiga2023processparameterselection pages 1-2, chepiga2023processparameterselection pages 2-4). Optimized parameters included laser power, scanning speed, hatch spacing, layer thickness, and scan rotation angle. The authors identified VED as an imperfect but useful comparative metric and noted its limitations (chepiga2023processparameterselection pages 1-2, chepiga2023processparameterselection pages 7-9).

**Heddar et al. (2024, Int. J. Adv. Manuf. Technol.)** presented an adaptable multi-objective optimization framework for metal additive manufacturing combining GP surrogate models with sensitivity analysis and evolutionary MOO (NSGA-II). Their workflow targets part density and surface roughness (Ra) with laser power, scan speed, and hatch distance as primary decision variables (heddar2024adaptablemultiobjectiveoptimization pages 30-34, heddar2024adaptablemultiobjectiveoptimization pages 6-10, heddar2024adaptablemultiobjectiveoptimization pages 1-6). Sensitivity analysis revealed hatch distance strongly influences surface roughness while laser speed and power jointly affect porosity (heddar2024adaptablemultiobjectiveoptimization pages 1-6). The framework supports continuous Bayesian optimization refinement using acquisition functions on fitted GPs (heddar2024adaptablemultiobjectiveoptimization pages 6-10).

**Zhang, Parnell, Brabazon & Benavoli (2021, arXiv)** reviewed Bayesian optimization for sequential experimental design in additive manufacturing, documenting applications including lattice/unit-cell design, material-distribution optimization, and process parameter tuning (zhang2021bayesianoptimisationfor pages 8-11, zhang2021bayesianoptimisationfor pages 1-4). They noted that BO in AM is nascent but highlighted capabilities for batch, constrained, discrete-variable, multi-fidelity, and multi-objective optimization that are particularly relevant to AM experiments (zhang2021bayesianoptimisationfor pages 1-4).

**Karkaria et al. (2024, J. Manuf. Systems)** developed a digital twin framework integrating Bayesian optimization with machine learning for directed energy deposition (DED), introducing BOTSPO (Bayesian Optimization for Time Series Process Optimization) which optimizes laser power profiles to control thermal history and improve mechanical properties (karkaria2024towardsadigital pages 2-3, karkaria2024towardsadigital pages 1-2).

Additional relevant references from the literature include GP-based spatial models for porosity prediction in LPBF, Bayesian process optimization for additively manufactured Nitinol, and uncertainty-aware multi-objective BO frameworks with diversity-guided batch evaluations — all referenced in the LPBF optimization literature (chepiga2023processparameterselection pages 10-11). The broader ML-for-LPBF literature also includes Bayesian network models for SLM quality prediction and feature-dimension-ascended approaches for part density optimization.

**Key gap:** Most published BO work for LPBF optimizes only 2–4 parameters (typically laser power, scan speed, hatch spacing, and layer thickness). The challenge of simultaneously optimizing 6–10 parameters including scan strategy, contour passes, and thermal management — as proposed in your Tier A — has not been addressed in the LPBF-specific BO literature, though the high-dimensional BO methods reviewed in Section (b) provide the necessary tools. The integration of BO into a full alloy-discovery pipeline via function networks, as you propose, would be novel.

## Summary of Practical Recommendations

1. **Sub-node decomposition** of Node 2 is theoretically sound and practically beneficial for the BOFN framework. Aim for 2–4 inputs per sub-node.
2. **Use SAASBO** at each LPBF sub-node for automatic variable selection with scarce data; **TuRBO** as an alternative for local process window search; **MORBO** if multi-objective optimization is needed.
3. **Use RGPE** for transfer learning across alloy compositions — it is the most practical, BoTorch-compatible method that automatically handles dissimilar source tasks.
4. **Decompose the 6 powder properties** into multiple scalar nodes or apply dimensionality reduction before feeding into LPBF sub-nodes; the BOFN framework handles this natively.
5. **Existing LPBF BO work** (Chepiga et al. 2023; Heddar et al. 2024) validates the GP+MOBO approach for process parameter optimization but has not yet tackled the full 6–10 parameter Tier A space within a function network — your proposed work would be a significant contribution.
